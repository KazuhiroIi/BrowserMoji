| canny | 0.1055 | 0.2919 | 0.1429 | +0.037 / -0.149 |

- 全手法が細筆GTでスコア向上 (skel_R が全体的に高く、細筆は recall が取りやすいため)。最大の伸びは **pca** (+0.133)。pca は細筆のスパースGTの skel_R が 0.7219 と全手法最高
- baseline は太筆→細筆で不動 (0.277→0.366)。pca と baseline の差が 0.136 → 0.093 と縮まるが、順位は入れ替わらず baseline が1位
- pca は skel_P が 0.1709 と低い。細筆GTでは「書かれていない線は無視」なので、この低 skel_P は本来は見るべき値ではない (詳細は下)

## 解釈 (スパースGT向けペナルティを軽くする前提)

- 細筆GTは recall 志向のスパースアノテーションのため、**skel_P / P_cell の低さは必ずしも悪くない**。正しくは「recall (skel_R, R_cell) を確保しつつ精度をどう落とさないか」で見る
- skel_R で見ると: pca 0.7219 > baseline 0.6908 > nms 0.4822 > b2 0.4645 > canny 0.4007。**pca は細筆の「最低限検出してほしい線」を最も拾えている**
- β=2.0 の skel_F2.0 (recall を重視した読み方) では baseline 0.5045 / pca 0.4299 / b2 0.2911 / canny 0.2289 / nms 0.2180
- **baseline vs pca vs b2**:
  - 色の濃い線は baseline (low threshold) が最強だが、P_cell が 0.167 と低くセルあたりの選別が弱い (大量にセルを打つほど recall が伸びる戦略になっている)
  - pca は精度と recall の両立が最も良く、特に β=1.0 以上ではほぼ一貫して2位。しかも精度を上げる **pca と baseline の併用** が、recall を犠牲にしない精度向上の最有力候補
  - b2 は精度志向 (P_cell 0.399) だが skel_R が 0.465 に落ち、スパースGTでは見づらい
- **目視確認** (overlay/): baseline は scene1 などで建物の面 (エッジでない領域) を大量に誤爆。pca は顔輪郭や目鼻口のラインを比較的拾う。canny/nms/b2 は線そのものが薄すぎて GT をほぼ拾えていない

## 結論

- **β によるランキング変化は skel_Fβ ではほぼ無い** (baseline > pca > b2 > canny > nms が全 β で不変)。セル Fβ でも pca/b2 の入れ替わりと baseline の逆転が見える程度
- 細筆GTでは **recall を見るのが妥当**。recall で pca が全手法最高 (skel_R 0.7219)、baseline が次点 (0.6908)
- 太筆からの順位変化: 細筆GTでは canny/b2 が比較的改善する (セル F1_cell で b2 0.2957 は baseline 0.2311 より良い) が、skel レベルの実力順は不変
- 最終構成の候補:
  1. **baseline で recall を確保しつつ、pca を精度ブーストとして上乗せ** (pca の skel_R 0.7219 は全手法最高で、低 skel_P はスパースGTのペナルティ最小化と整合)
  2. β>1.0 (例: F2.0) を主指標にする細筆GT前提の採点方式
  3. 太筆との乖離を考慮するなら canny/b2 は精度寄りの閾値を緩めて recall を上げる余地がある (canny の skel_R 0.4007 は最低)
