# step6b: 1600px スケール向け しきい値再調整 結果

採点: `explore-2/step1/score.py` 互換 (幅1600px, cols=100, 16pxセル, 15画像)。主指標 = skel_F1。
再現確認: baseline q0.85 → skel_F1 0.2770, canny ratio>0.1 → 0.1055 (step6 と完全一致)。

測定コード: `retune.py` (詳細データ: `retune_results.json`)。しきい値感度の観点から 3 種類の値を併記する。

- **固定しきい値**: 全画像で同じ設定を使った場合の MEAN (実運用に近い値)
- **oracle**: 画像ごとに手法内の最良設定を選んだ場合の MEAN skel_F1 (しきい値感度の上限の参考値。train/test 分離のない実験なので過大評価側)
- **適応閾値モード (adaptive)**: 各画像で「予測エッジセル数 = 正解エッジセル数 (gt_cells)」になるようセル強度上位 K を選ぶ quantile ベース。予測セル数を正解に揃えた最も公平な比較。

## oracle (画像ごとに最良設定を選んだ場合の skel_F1 上限)

| method | oracle MEAN skel_F1 | 備考 |
|---|---|---|
| baseline | 0.3512 | 固定 q0.80 が全画像で最良 → しきい値感度は「緩める」単調方向 |
| canny | 0.2919 | 固定 ratio>0.04 がほぼ全画像で最良 → 同上 |
| pca | 0.2007 | 固定 (px>=5, sig<0.30) がほぼ全画像で最良 |
| b2 | 0.1436 | 同上 (px>=5) |
| adaptive | 0.2708 | 適応モード全体の最良 (canny top-K) |
| nms | 0.0661 | r=2 固定が最良 |

ほとんどの手法で「最も緩い固定しきい値」がそのまま oracle になる。つまり 1600px での課題はしきい値微調整ではなく「絶対量の不足」であり、緩める方向への一様な感度しかない。
