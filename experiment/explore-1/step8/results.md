# step8: pca-canny ベストへの後段ステージ追加検証

ベース: step7 best `pca-canny/mep5_r0.35_er0.02` (MIN_EDGE_PX=5 / σ2σ1<0.35 / edge_rate>=0.02)
採点: step6c `score_thin.py` 方式 (細筆GT 15枚, brush_dilate=1, sigma=2.0)
実装: `step8/improve.py` / 出力: `step8/results.json`, `step8/overlay/{variant}/{stem}.jpg`

## 追加ステージ

| ステージ | 内容 |
|---|---|
| chain | 方向一貫性チェーン: 各セルの主軸 θ を 8近傍接続 (方向差<=45°)、チェーン長>=3 のみ採用 (step6 predictors._chain を流用) |
| clean | 孤立セル除去: 白セルの8近傍連結成分 <5 セルをフィラー化 (predictors._clean) |
| stripe | 横縞抑制: セル勾配の異方性 \|gy\|/(\|gy\|+\|gx\|) > 0.60 かつ主軸 θ がほぼ水平 (差<=30°) のセルを「帯セル」化 → 8近傍連結成分が横長 (列スパン>=8) の縞テクスチャ成分について、列ごとの縦ラン (ギャップ<=2行) 内で最もエッジ強度 (セル内エッジ画素数) が高い1行のみ残す |

variant: `base` / `+clean` / `+chain` / `+chain+clean` / `+stripe` / `+stripe+clean`

## 目視観察 (overlay/face2, scene2, high_contrast1)

- **scene2 タワー横縞**: base では中層の横縞テクスチャがブロック状に大量誤爆。
  `+stripe` で帯セルの縦ランが最強1行に間引きされ、**タワー中層はほぼ消える**
  (輪郭・窓枠の縦ラインは温存)。この画像に限ると skel_P はむしろ低下するが、
  誤爆の面積が大幅に減り見た目は明確に改善。
- **水面反射像**: 追加ステージでは効かない。反射の輪郭は縦長の成分で θ も縦寄り、
  chain でも「縦に長いチェーン」になって落ちない。孤立除去も成分が大きいため無効。
  反射への対策は勾配方向では分離できない (本物の縁と同質) ので別枠 (輝度等) が必要。
- **face2 / high_contrast1**: clean/chain は輪郭チェーンまで削ることがあり
  (短い輪郭断片や角のセルが <5 成分 / チェーン長<3 になる)、skel_R を 
  0.80→0.72 まで落とす。GT 細線の細切れを削るのが原因。
- **stripe は GT への侵食も軽微**: R_cell の低下はごく小さい一方、横縞誤爆にだけ効く
  ターゲットを絞ったフィルタとして機能している。

## 結論・推奨

- skel_F1 (MEAN) の数値基準では **base が最良 (0.3714)**。
  どの後段ステージも GT 細線も削るため、数値は下がる方向。
- ただし視覚品質 (横縞誤爆の抑制) では `+stripe` が最も効果が大きく、
  MEAN の skel_F1 低下はわずか 0.013 (0.3714→0.3583)。
  scene2 のタワー中層の誤爆がほぼ消えるので、**表示品質重視なら `+stripe` を推奨**。
- `+clean` / `+chain` は単独では GT 細線を削りすぎて非推奨。
  特に chain+clean の併用は skel_R を 0.80→0.69 まで落とす。
- 残る弱点 (水面反射の輪郭追従) は本ステージでは解決せず、次段の課題。
