# D-005: リポジトリのライセンスは MIT を仮置き

- 状態: 🔶（仮決め・Q-2 は F-17 採否と合わせて決定）
- 関連: N-7, requirements.md Q-2, F-17

## 背景

リポジトリを公開する（G-4）ためライセンスの明示が必要（N-7）。ただし F-17（YOLO26-sem によるセグメンテーション）を採用する場合、モデル側のライセンス（AGPL-3.0 など）との整合を確認する必要があり、最終判断は F-17 の採否と合わせて行う（Q-2）。

## 選択肢

1. **MIT を仮置きし、F-17 採用時に見直す**
2. 最初から AGPL-3.0 にする
3. ライセンスファイルを置かず未決のままにする

## 決定

- リポジトリのライセンスは **MIT** を仮置きする
- F-17 の採否と合わせて Q-2 を改めて決定し、必要なら差し替える
- LICENSE ファイル自体には仮置きである旨の注記を書かない。判断の経過は本ファイル（docs/decisions/）で管理する

## 理由

- セグメンテーションを有効にしない現状のコード（カメラ→変換・表示のみ）に AGPL を強制する根拠はまだない
- LICENSE を置かないままにすると、公開リポジトリとして利用条件が不明になる。MIT は後から他のライセンスへ差し替えやすい（寄与の扱いは差し替え時に改めて確認する）
