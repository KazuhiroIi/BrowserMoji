# D-004: EXP-1（描画方式）の進め方 — Canvas 2D 先行、WebGL2 を後から比較

- 状態: 🔶（仮決め）
- 関連: architecture.md §5, EXP-1

## 背景

architecture.md §5 では「基準（最低限動かす）は WebGL2」としたが、これは推測に基づく順序でしかない（設計原則 4: 実機計測を先に行う）。Week 1 でまず動くものを作り、低スペック端末での実測で決定したい。

## 選択肢

1. **Canvas 2D を先行実装・公開し、その後 WebGL2 を追加して比較する**
2. 最初から WebGL2 で実装する
3. DOM（`<pre>`）で先行実装する

## 決定

- まず **Canvas 2D 版**（CPU パイプライン + アトラス転写）を実装・公開する
- その後 **WebGL2 版**を Renderer の別実装として追加し、低スペック端末で fps を比較して描画方式を決定する
- 結論は EXP-1 の結果として docs/experiments/ に記録し、必要なら本決定を更新する

## 理由

- Canvas 2D 版は CPU の基準実装（N-4）を兼ねる。まず完全なパイプラインを動かすことで、後段の GPU 移行時の比較対象ができる
- WebGL2 の複雑さは描画側だけで済む。FeatureExtractor / GlyphSelector の実装は描画方式に依存しない形にしておく
- DOM 方式は全角グリッドが端末依存で崩れる（N-5）ため、比較対象から外す
